Interface web do projeto **SmartVest**, uma plataforma educacional interativa sobre investimentos. Desenvolvida como uma *Single Page Application* (SPA) moderna e responsiva.

## 🚀 Funcionalidades da Interface

* **Chatbot Interativo:** Widget de chat integrado para tirar dúvidas com IA.
* **Área de Conteúdo:** Navegação por tópicos (Renda Fixa, Ações, etc.) com vídeos e textos.
* **Autenticação:** Telas de Login e Registro com suporte a Google OAuth.
* **Responsividade:** Layout adaptável para desktop e mobile.

## 🛠️ Pré-requisitos

* **Node.js** (versão 18 ou superior)
* **Backend do SmartVest** rodando localmente (para a API funcionar).

## 📦 Como Rodar

1.  **Instale as dependências:**
    ```bash
    npm install
    ```

2.  **Configure as Variáveis de Ambiente:**
    Crie um arquivo `.env` na raiz e aponte para o seu backend (padrão):
    ```ini
    VITE_API_URL=[http://127.0.0.1:8000](http://127.0.0.1:8000)
    ```

3.  **Inicie o servidor de desenvolvimento:**
    ```bash
    npm run dev
    ```

4.  Acesse no navegador: `http://localhost:5173`
